# ۲. عیب‌یابی خطاهای تایم‌اوت، ۵۰۴ و کمبود حافظه (Memory Limit)

> **بخش:** عیب‌یابی • **نسخه پایدار:** ۱.۰.۰ رسمی • **آخرین به‌روزرسانی:** نوامبر ۲۰۲۶  
> **مخاطب:** کاربران هاست‌های اشتراکی و ادمین‌های سرور

---

## 🛑 ۱. خطای `504 Gateway Timeout` یا فریز شدن نوار درصد

### نشانه:
در حین بکاپ‌گیری، نوار پیشرفت روی درصدی ثابت می‌ماند یا در تب شبکه مرورگر خطای `504 Gateway Timeout` از سمت وب‌سرور برگشت داده می‌شود.

### علت:
وب‌سرورهایی مانند لایت‌اسپید یا انجین‌ایکس دارای سقف تایم‌اوت برای اتصالات هستند (معمولاً ۳۰ تا ۶۰ ثانیه). اگر یک فرآیند بیشتر از این مدت زمان ببرد، اتصال قطع می‌شود.

### راه‌حل‌ها:
1. **طراحی خودکار بکاپینو:**  
   نیازی به نگرانی نیست! در بکاپینو حتی اگر اتصال بریده شود، اسکریپت با تیکت‌های ایجکس قطعه‌بندی‌شده (Chunked) در پس‌زمینه ادامه می‌دهد. کافی است صفحه را پس از ۱ دقیقه رفرش کنید؛ خواهید دید که درصد پیشرفت افزایش یافته و ادامه فرآیند در حال اجراست.
2. **کاهش دسته فایل‌ها (Chunk Size):**  
   اگر هاست شما بسیار ضعیف است، در منوی **بکاپینو ← تنظیمات ← تب بایگانی و استثناها**، گزینه «تعداد فایل‌های بسته‌بندی در هر درخواست» را از ۳۰۰ به **۱۰۰ یا ۱۵۰ فایل** کاهش دهید.
3. **افزایش تایم‌اوت در `.htaccess`:**
   ```apache
   php_value max_execution_time 300
   php_value max_input_time 300
   ```

## 🛑 ۲. خطای کمبود حافظه `Allowed memory size of ... bytes exhausted`

### نشانه:
خطای مشهور Fatal error: Allowed memory size of X bytes exhausted.

### راه‌حل‌ها:
1. **افزایش حافظه در `wp-config.php`:**  
   خطوط زیر را قبل از خط `/* That's all, stop editing! Happy publishing. */` در فایل `wp-config.php` قرار دهید:
   ```php
   define( 'WP_MEMORY_LIMIT', '256M' );
   define( 'WP_MAX_MEMORY_LIMIT', '512M' );
   ```
2. **افزایش در فایل `.htaccess` یا `php.ini`:**
   ```ini
   memory_limit = 256M
   ```
3. **مستثنی کردن فایل‌های سنگین:**  
   در تنظیمات بکاپینو، گزینه نادیده گرفتن فایل‌های بزرگ‌تر از ۵۰ یا ۱۰۰ مگابایت را فعال کنید.
