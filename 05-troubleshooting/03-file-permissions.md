# ۳. عیب‌یابی مجوزهای دسترسی فایل‌ها و پوشه‌ها (File Permissions)

> **بخش:** عیب‌یابی • **نسخه پایدار:** ۱.۰.۰ رسمی • **آخرین به‌روزرسانی:** نوامبر ۲۰۲۶  
> **مخاطب:** مدیران لینوکس، وب‌مسترها و پشتیبان‌های سرور

---

## 🔒 ۱. خطای `Root directory is not writable` در اینستالر

### نشانه:
در مرحله ۱ فایل `installer.php`، تاییدیه نیازمندی‌ها خطای قرمز رنگ می‌دهد و اعلام می‌کند که پوشه ریشه سرور قابل نوشتن نیست.

### علت:
کاربر وب‌سرور (مانند `nobody`، `www-data` یا `cpanel_user`) مجوز ایجاد فایل و دایرکتوری در مسیر ریشه وب ندارد.

### راه‌حل‌ها:
1. **بررسی پرمیشن پوشه:**  
   در File Manager هاست، پرمیشن پوشه `public_html` را بررسی کنید. باید دقیقاً عدد **`755`** باشد.
2. **اصلاح مالکیت در سرورهای لینوکسی و اختصاصی (Ownership):**
   ```bash
   # برای هاست‌های مبتنی بر سی‌پنل / دایرکت‌ادمین:
   chown -R cpaneluser:cpaneluser /home/cpaneluser/public_html
   chmod 755 /home/cpaneluser/public_html

   # برای وب‌سرورهای آپاچی و انجین‌ایکس خام:
   chown -R www-data:www-data /var/www/html
   chmod -R 755 /var/www/html
   ```

---

## 🔒 ۲. خطای ناتوانی در نوشتن فایل آرشیو (`Could not write the package file`)

### نشانه:
در مرحله فشرده‌سازی در پیشخوان وردپرس، فرآیند متوقف شده و اعلام می‌کند نوشتن روی دیسک ناموفق بوده است.

### راه‌حل‌ها:
1. بررسی کنید که پوشه `wp-content/` مجوز `755` داشته باشد تا پوشه `wp-content/backupino/` بدون خطا ساخته شود.
2. اطمینان حاصل کنید که فضای هاست یا سهمیه هارد (Disk Quota) در کنترل‌پنل پر نشده باشد (`Disk Space 100% Full`).
3. در تب وضعیت سرور تنظیمات بکاپینو، فضای خالی دیسک را بررسی نمایید.
