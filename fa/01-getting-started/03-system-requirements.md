## 💻 مشخصات فنی مورد نیاز

بکاپینو طوری طراحی شده است که در حداقل منابع ممکن و بدون نیاز به نصب هیچ‌گونه باینری اضافی در سرور کار کند. جدول زیر خلاصه مشخصات پیشنهادی و حداقل‌ها را نشان می‌دهد:

| مؤلفه | حداقل الزامی | مقدار پیشنهادی |
|---|---|---|
| **نسخه PHP** | PHP 7.4 | PHP 8.1 / 8.2 / 8.3 / 8.4 |
| **نسخه وردپرس** | WordPress 6.0 | WordPress 6.5 / 6.7+ |
| **نسخه MySQL / MariaDB** | MySQL 5.7 / MariaDB 10.2 | MySQL 8.0+ / MariaDB 10.6+ |
| **حافظه موقت (Memory Limit)** | ۶۴ مگابایت | ۱۲۸ یا ۲۵۶ مگابایت |
| **حداکثر زمان اجرا (`max_execution_time`)** | ۳۰ ثانیه | ۶۰ ثانیه به بالا (یا ۳۰۰ در هاست اشتراکی) |
| **اندازه پکت دیتابیس (`max_allowed_packet`)** | ۱۶ مگابایت | ۶۴ مگابایت یا بالاتر |

## 🧩 اکستنشن‌های الزامی و اختیاری PHP

در هنگام فعال‌سازی و در تب «وضعیت سلامت سیستم» تنظیمات بکاپینو، وضعیت ماژول‌های زیر اعتبارسنجی می‌شود:

### اکستنشن‌های الزامی (Required):
1. **`pdo_mysql` یا `mysqli`:** جهت اتصال ایمن به پایگاه داده و استریم جداول.
2. **`json`:** برای کدگذاری و تحلیل مانیفست پکیج و تنظیمات.
3. **`zip` یا کتابخانه پیش‌فرض `PclZip`:** جهت ایجاد و بازگشایی آرشیو‌های زیپ استاندارد.

### اکستنشن‌های پیشنهادی (Recommended):
* **`mbstring`:** برای پردازش دقیق کاراکترهای چندبایتی فارسی و جلوگیری از برش نامک‌های طولانی مقالات.
* **`openssl`:** جهت برقراری ارتباط امن HTTPS برای ارسال اعلان‌های وب‌هوک به تلگرام و بله و آپلودهای ابری.
* **`curl`:** برای اجرای اتصالات سریع شبکه در وردپرس.

## 🌐 سازگاری با وب‌سرورها و سیستم‌عامل‌ها

بکاپینو به صورت گسترده بر روی پلتفرم‌های زیر آزمایش و اعتبارسنجی شده است:

* **وب‌سرورها:**
  * Apache 2.4+ (با ماژول `mod_rewrite`)
  * LiteSpeed و OpenLiteSpeed
  * Nginx (به همراه PHP-FPM)
  * Microsoft IIS 8.5+
* **سیستم‌عامل‌های سرور:**
  * لینوکس (Ubuntu, Debian, CentOS, AlmaLinux, Rocky Linux, CloudLinux)
  * ویندوز سرور و ویندوز ۱۰/۱۱ (برای محیط‌های محلی)
  * macOS (از طریق MAMP یا Homebrew)
* **کنترل‌پنل‌های هاستینگ:**
  * cPanel و WHM
  * DirectAdmin
  * Plesk
  * CyberPanel و aaPanel
  * Cloudways و RunCloud

## 🔒 سطوح دسترسی فایل‌ها (File Permissions)

برای عملکرد صحیح فشرده‌سازی و تولید فایل نصاب:
* پوشه `wp-content/` باید دسترسی استاندارد **`755`** (یا `drwxr-xr-x`) داشته باشد.
* پوشه اختصاصی `wp-content/backupino/` توسط افزونه با دسترسی امن ساخته شده و دسترسی وب آن با فایل‌های زیر محافظت می‌شود:
  * فایل `.htaccess` با عبارت `Deny from all`
  * فایل `index.php` برای مسدودسازی فهرست‌بندی دایرکتوری (Directory Browsing)
