## 🎯 Why Notifications via Bale Messenger?

The financial and communication messenger **Bale** is widely used in Iran and offers unique operational advantages for websites hosted in the region:
* **100% Compatibility with the National Information Network (NIN):** Operates reliably on all domestic Iranian hosting providers (such as AbrArvan, Pars Online, Tebyan, Shatel, etc.) without requiring proxies, VPNs, or international routing.
* **Instant and Uninterrupted Delivery:** Remains fully functional without disruptions during international internet throttling or connectivity anomalies.
* **Rich Messaging Capabilities:** Native support for inline buttons and Markdown formatted hyperlinks.

## 🤖 Step-by-Step Bale Bot Creation

### Step 1: Open BotFather in Bale
1. Open the Bale mobile application or web client.
2. In the search bar, enter the official bot-builder ID:  
   `@BotFather`
3. Open the chat with BotFather and click **Start**.
4. Send the command `/newbot`.

### Step 2: Choose Bot Name and Username
1. Enter a display name for your bot (e.g., `Backupino Reports`).
2. Specify a unique English username ending with `bot` (e.g., `mybrand_backup_bot`).
3. BotFather will return an access token:
   ```text
   123456789:ABCDefgh-IJKLmnopQRSTuvwxyz
   ```
   Copy this token securely.

### Step 3: Start the Bot and Obtain Your Chat ID
1. Search for your newly created bot in Bale and open the chat window.
2. Tap **Start** to initialize conversation privileges.
3. To obtain your numeric user Chat ID, you can use user-info helper bots in Bale or reference your user account ID.

## ⚙️ Configuration in the Backupino Dashboard

1. In your WordPress admin dashboard, navigate to **Backupino → Settings → Notifications tab**.
2. Configure the following fields:
   * **Messenger Service:** `Bale`
   * **Bot Token:** Paste the token generated by Bale's BotFather.
   * **Chat ID:** Enter your user Chat ID in Bale.
3. Click **Save Settings**.
4. Click **Send Test Message**. In less than 3 seconds, a success notification with clickable blue hyperlinks will arrive in your Bale app.
